この学習サイト自体が、Cloudflare の様々な機能を組み合わせて構築されたフルスタックアプリケーションです。

## 技術スタックの構成

- **フロントエンド**: Next.js (App Router) + OpenNext
- **バックエンド API**: Hono Worker
- **データベース**: D1 + Drizzle ORM
- **オブジェクトストレージ**: R2
- **Durable Objects**: チャット/アラーム等
